# 🍽️ Sistema de Gestión para Restaurantes

Sistema web para gestionar ventas, inventario y compras de tu restaurante. **Seguro, rápido y fácil de usar.**

---

## 📋 ¿Qué puedo hacer?

### Operación Diaria
- 💰 Registrar ventas
- 📦 Ver y actualizar stock
- 🍽️ Crear recetas de comidas preparadas
- 🛒 Registrar compras a proveedores
- ⚠️ Recibir alertas de stock bajo

### Reportes
- 📊 Dashboard con resumen del día
- 📈 Ventas totales y por producto
- 💵 Ganancias y costos
- 📉 Análisis de inventario

### Descargar Mis Datos
- 📥 Descarga tus ventas (CSV o JSON)
- 📥 Descarga productos y stock
- 📥 Descarga historial completo
- **Solo click, sin necesidad de código**

---

## 🔐 Acceso

Recibe tu email y contraseña del administrador.

| Rol | Puedo... |
|-----|---------|
| **Administrador** | Todo: ventas, compras, reportes |
| **Vendedor** | Registrar ventas y ver stock |
| **Inventario** | Gestionar stock y compras |

---

## 📥 Descargar Mis Datos

**Cuando necesites hacer respaldo o cambiar de sistema:**

1. Ve a **Perfil** (esquina superior derecha)
2. Selecciona **Descargar Datos**
3. Elige qué descargar:
   - Mis ventas
   - Productos
   - Inventario
   - Compras
   - Todo junto
4. Elige formato: CSV o JSON
5. ¡Listo! Se descarga automáticamente
